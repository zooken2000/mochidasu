# もちだす — コンセプトと仕様メモ

## 一言で
自分を説明する言葉は、もう誰かが書いている。それを持ち歩けるようにするツール。

## 対象の紙
- 職場のサンクスカード・退職色紙
- 学生団体の寄せ書きアルバム
- 中学の卒業寄せ書き（小学校分は内輪ネタ中心のため対象外）

## 出口
「懐かしむ」ではなく「自分を説明する材料が持てる」こと。
職務経歴書・自己紹介・面談前のメモに貼れるテキストとして持ち出す。

## 抽出ルール（エージェントの system prompt と対応）
| 残す | 除外する |
|---|---|
| 人柄・仕事ぶり・関わり方・強みの具体的な記述 | 定型の挨拶のみ（お疲れさま／頑張って） |
| エピソード付きの感謝 | 本人への言及がない内輪ネタ・書き手の近況 |
| | 絵・スタンプのみ |

- 原文のまま写す（要約・言い換えしない）
- 判読できない箇所は推測しない（unreadable_count）
- 複数の書き手に共通する特徴を keywords にまとめる

## 出力スキーマ
`packages/agent/mochidasu_agent/extractor/schema.py` の `Extraction` が正。
Web 側の型は OpenAPI から自動生成（`packages/web/src/generated/extractor/`）。
