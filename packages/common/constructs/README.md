# @mochidasu/common-constructs

Shared CDK constructs used by `@mochidasu/infra`.

| Construct | File | Notes |
|---|---|---|
| `GuestIdentity` | `src/core/guest-identity.ts` | Cognito identity pool for sign-in-free access. Publishes `cognitoProps` to the runtime config |
| `Extractor` | `src/app/agents/extractor/extractor.ts` | AgentCore Runtime for the agent, IAM auth, `grantInvokeAccess()` |
| `Web` | `src/app/static-websites/web.ts` | CloudFront + S3 static site that serves `runtime-config.json` |
| `UserIdentity` | `src/core/user-identity.ts` | Generated Cognito user pool construct. Not used by the stack; `featurePlan` was added |
| `RuntimeConfig` | `src/core/runtime-config.ts` | Passes config to the web app (S3) and the agent (AppConfig) |

Most files were generated by Nx Plugin for AWS. `guest-identity.ts` and the IAM-auth version of `extractor.ts` were written or adapted for this project.
